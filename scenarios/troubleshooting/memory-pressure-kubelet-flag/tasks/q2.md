After a maintenance window, one of the workers reports `MemoryPressure` and keeps evicting Pods, although nothing on it uses much memory. DaemonSet `node-agent` in namespace `${Q2_NS}` is meant to run a ready Pod on every worker.

Someone already checked `/var/lib/kubelet/config.yaml` on that worker: it is correct, so do not change it.

Find the node and fix it so that:

- every node is `Ready` and none is under `MemoryPressure`
- `node-agent` runs a ready Pod on every worker
- the kubelet is running and enabled, and the fix survives a reboot of the node

Do not change the DaemonSet, and do not rejoin the node to the cluster.
