When a node runs short of memory, the kubelet evicts Pods, and `Guaranteed` Pods go last. The team wants Deployment `${Q1_APP}` in namespace `${Q1_NS}` protected this way.

Change it so that its Pods have QoS class `Guaranteed`, with these requests:

- container `api`: `100m` CPU and `128Mi` memory
- container `shipper`: `50m` CPU and `32Mi` memory
- init container `prepare`: `20m` CPU and `16Mi` memory

Keep the replica count at `2`, and do not delete or recreate the Deployment.
