Use context: `kubectl config use-context k8s-gamma`

The cluster must stop using the nodes' resolvers. Change the CoreDNS configuration so that every name outside the cluster is forwarded to the company DNS server, Service `resolver` in namespace `corp-dns`, instead of to `/etc/resolv.conf`. Cluster names must keep resolving. The company server is the only one that knows `intranet.${Q17_ZONE}`:

```bash
kubectl -n ${Q17_NS} exec dns-test -- nslookup intranet.${Q17_ZONE}
kubectl -n ${Q17_NS} exec dns-test -- nslookup web.${Q17_NS}.svc.cluster.local
```

Keep CoreDNS running with `2` replicas.
