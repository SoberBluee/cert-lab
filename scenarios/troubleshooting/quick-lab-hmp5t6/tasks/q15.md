Use context: `kubectl config use-context k8s-batch`

Take a snapshot of the cluster's etcd database and save it on `controlplane` at `${Q15_BACKUP}`. etcd runs as a static Pod on `controlplane` and only accepts TLS clients; the snapshot must include ConfigMap `${Q15_MARKER}` in namespace `default`.

- Save the status of the snapshot, as printed by `etcdctl snapshot status` in table format, to `${Q15_STATUS_FILE}` on `controlplane`.
