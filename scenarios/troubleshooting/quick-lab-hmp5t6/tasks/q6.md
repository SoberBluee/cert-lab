Use context: `kubectl config use-context k8s-edge`

1. Create a Pod `${Q6_NAME}` in namespace `${Q6_NS}` with one container `main` running image `${Q6_IMAGE}`. It must keep running.

   - The container runs as user `${Q6_SEC_USER}`, with a read-only root filesystem and no privilege escalation.
   - Add a liveness probe that runs `ls /` in the container every `${Q6_PROBE_PERIOD}` seconds.
   - Create a Secret `${Q6_ENV_OBJ}` with the key `${Q6_ENV_KEY}` set to `${Q6_ENV_VALUE}`, and give the container `${Q6_ENV_KEY}` as an environment variable taken from it.

2. Then add the label `${Q6_LABEL_KEY}=${Q6_LABEL_VALUE}` to the running Pod `${Q6_NAME}`, without recreating it.
