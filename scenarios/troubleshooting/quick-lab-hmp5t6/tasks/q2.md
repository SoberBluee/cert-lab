Pods in namespace `${Q2_NS}` can no longer reach Service `web` by name. Fix the cluster so that both of these work again:

```bash
kubectl -n ${Q2_NS} exec ${Q2_CLIENT} -- wget -qO- -T 3 http://web
kubectl -n ${Q2_NS} exec ${Q2_CLIENT} -- nslookup web.${Q2_NS}.svc.cluster.local
```

Keep CoreDNS as the cluster DNS with `2` replicas, and keep forwarding other names to the node's resolver. Do not delete or recreate Deployment `web` or Service `web`. You may recreate Pod `${Q2_CLIENT}` with the same name, image and command.
