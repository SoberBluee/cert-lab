The cluster's Traefik controller serves Ingress and Gateway API traffic on NodePort `30080` of every node. In namespace `${Q4_NS}`, Deployment `${Q4_APP}` is published on two hosts, and users report that one of them no longer shows the nginx welcome page.

Both of these must return the nginx welcome page:

```bash
curl -H 'Host: www.${Q4_NS}.lab' http://controlplane:30080/
curl -H 'Host: api.${Q4_NS}.lab' http://controlplane:30080/
```

The intended setup is:

- Service `${Q4_APP}`: port `80`, forwarding to the `${Q4_APP}` Pods
- Ingress `${Q4_APP}`: class `traefik`, host `www.${Q4_NS}.lab`, path `/` (`Prefix`) to Service `${Q4_APP}` on port `80`
- HTTPRoute `${Q4_APP}`: attached to the `web` listener of Gateway `traefik-gateway` in namespace `traefik`, host `api.${Q4_NS}.lab`, to Service `${Q4_APP}` on port `80`

Fix it without changing the Deployment or the Service, and without deleting the Ingress or the HTTPRoute.
