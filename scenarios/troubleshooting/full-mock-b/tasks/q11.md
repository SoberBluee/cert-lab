Use context: `kubectl config use-context k8s-green`

1. Work on `controlplane` as user `ubuntu`. Add the Helm repository `http://controlplane:8879` under the name `lab`, then install release `${Q11_REL}` from chart `lab/webapp` at version `${Q11_VERSION}` into namespace `${Q11_NS}`.

2. Then save the manifests that release `${Q11_REL}` installed, as Helm stored them, to `/opt/course/helm/${Q11_REL}-manifest.yaml` on `controlplane`.

3. Then upgrade release `${Q11_REL}` to chart version `2.0.0`, keeping the values you set.
