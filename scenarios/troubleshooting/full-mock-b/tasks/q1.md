Use context: `kubectl config use-context k8s-web`

1. Create a CronJob `${Q1_NAME}` in namespace `${Q1_NS}` on the schedule `${Q1_SCHEDULE}`. Each Job runs `${Q1_COMPLETIONS}` completion(s) of a container with image `busybox:1.36` and the command `sh -c 'date; echo done'`.

2. Then suspend `${Q1_NAME}` so that it starts no new Jobs. Do not delete it.

3. Then trigger a run immediately by creating a Job `${Q1_NAME}-manual` from the CronJob, and let it finish.
