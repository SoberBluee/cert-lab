Use context: `kubectl config use-context k8s-edge`

1. Create a StorageClass `${Q9_NAME}` for statically provisioned volumes (provisioner `kubernetes.io/no-provisioner`) with reclaim policy `${Q9_RECLAIM}` and volume binding mode `${Q9_BINDING}`.

   - It must be the cluster default StorageClass.
   - Claims using it must be allowed to grow (volume expansion).

2. Then switch `${Q9_NAME}` from volume binding mode `${Q9_BINDING}` to the other mode. It must keep its name and every other setting.
