Use context: `kubectl config use-context k8s-west`

Take a snapshot of the cluster's etcd database and save it on `controlplane` at `${Q7_BACKUP}`. etcd runs as a static Pod on `controlplane` and only accepts TLS clients; the snapshot must include ConfigMap `${Q7_MARKER}` in namespace `default`.
