Use context: `kubectl config use-context k8s-beta`

The cluster's Traefik controller serves Ingress and Gateway API traffic on NodePort `30080` of every node. In namespace `${Q12_NS}`, Deployment `${Q12_APP}` is published on two hosts: Ingress `${Q12_APP}` serves `www.${Q12_NS}.lab` and HTTPRoute `${Q12_APP}` serves `api.${Q12_NS}.lab`. Users report that the app is not reachable on all of them.

Both of these must return the nginx welcome page:

```bash
curl -H 'Host: www.${Q12_NS}.lab' http://controlplane:30080/
curl -H 'Host: api.${Q12_NS}.lab' http://controlplane:30080/
```

Do not change the Deployment or the Service, and do not delete the Ingress or the HTTPRoute.
