Use context: `kubectl config use-context k8s-prod`

In namespace `${Q13_NS}`, Gateway `app-gw` serves `app.${Q13_NS}.lab` over HTTPS on its listener `https`, and HTTPRoute `web` sends every request to Service `web`. A canary release runs behind Service `web-canary` (port `80`).

Change HTTPRoute `web` so that requests carrying the header `X-Canary: always` go to `web-canary`, and all other requests still go to `web`. Do not create another HTTPRoute.

Traefik serves the listener on NodePort `30443` of every node:

```bash
curl -k --resolve app.${Q13_NS}.lab:30443:$(getent hosts controlplane | awk '{print $1}') -H 'X-Canary: always' https://app.${Q13_NS}.lab:30443/
```
