Use context: `kubectl config use-context ${CTX_OPS}`

A node agent may only run on nodes that were explicitly enabled for it, and must only be updated when an operator says so.

1. Label node `${Q5_NODE}` with `agent=${Q5_DS}`.
2. In namespace `${Q5_NS}` (create it), create a DaemonSet `${Q5_DS}` with image `busybox:1.36` running `sleep infinity` and Pod label `app=${Q5_DS}`. It runs only on nodes labelled `agent=${Q5_DS}`, and its Pods are only replaced when they are deleted, never automatically.
3. Once its Pod is running, change the DaemonSet's command to `sleep 3600`, and make sure the running Pod uses the new command.
