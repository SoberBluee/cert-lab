Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Create a **static** Pod named `${Q4_POD}` in namespace `default` on node `${Q4_NODE}`:

- image `nginx:1.27-alpine`
- resource requests `10m` CPU and `20Mi` memory

Then make it reachable from outside the cluster: create a Service `${Q4_POD}-svc` of type `NodePort` in namespace `default` that sends port `80` to the static Pod, on node port `${Q4_NODEPORT}`. The Service must have the static Pod as its only endpoint.
