Use context: `kubectl config use-context kubernetes-admin@kubernetes`

1. Create a PersistentVolume `${Q4_NAME}` of `${Q4_CAPACITY}` with access mode `${Q4_ACCESS}`, reclaim policy `${Q4_RECLAIM}` and StorageClass `manual`, backed by the host directory `/srv/${Q4_NAME}` (created if missing).

   - The volume only exists on `${Q4_AFFINITY_NODE}`: give it a required node affinity on `kubernetes.io/hostname`.
   - It carries the label `tier=${Q4_LABEL_TIER}`.

2. Then change the capacity of `${Q4_NAME}` to `${Q4_RESIZE_CAPACITY}` without recreating it.

3. Then reserve `${Q4_NAME}` for a claim `${Q4_RESERVE_CLAIM}` in namespace `${Q4_RESERVE_NS}` that will be created later, so no other claim can take it.
