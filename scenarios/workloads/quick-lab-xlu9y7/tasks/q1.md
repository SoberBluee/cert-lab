Use context: `kubectl config use-context kubernetes-admin@kubernetes`

1. Create a Pod `${Q1_NAME}` in namespace `${Q1_NS}` with one container `main` running image `${Q1_IMAGE}`. It must keep running.

   - Add a liveness probe that runs `ls /` in the container every `${Q1_PROBE_PERIOD}` seconds.
   - Create a Secret `${Q1_FILES_OBJ}` with the key `${Q1_FILES_FILE}` set to `${Q1_FILES_VALUE}`, and mount it read-only at `/etc/app`, so the file `/etc/app/${Q1_FILES_FILE}` holds the value.
   - Create a ConfigMap `${Q1_ENV_OBJ}` with the key `${Q1_ENV_KEY}` set to `${Q1_ENV_VALUE}`, and give the container `${Q1_ENV_KEY}` as an environment variable taken from it.

2. Then add the annotation `${Q1_NOTE_KEY}=${Q1_NOTE_VALUE}` to the running Pod `${Q1_NAME}`, without recreating it.

3. Then add the label `${Q1_LABEL_KEY}=${Q1_LABEL_VALUE}` to the running Pod `${Q1_NAME}`, without recreating it.
