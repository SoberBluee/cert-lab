Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Every Pod of Deployment `${Q2_APP}` in namespace `${Q2_NS}` keeps about `80Mi` of data in memory.

Create a HorizontalPodAutoscaler `${Q2_APP}` that keeps it between `1` and `3` replicas, targeting an average of `50Mi` of memory per Pod.

Each new Pod loads the same data, so the average does not fall as the Deployment grows. Once the autoscaler works, it takes `${Q2_APP}` to `3` ready replicas by itself.
