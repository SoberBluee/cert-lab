1. Create a Pod `${Q2_NAME}` in namespace `${Q2_NS}` with one container `main` running image `busybox:1.37`. It must keep running.

   - The container runs as user `${Q2_SEC_USER}`, with a read-only root filesystem and no privilege escalation.
   - Mount an `emptyDir` volume named `data` at `/data`. The container runs a shell command that writes its hostname to `/data/out.log` and to standard output once, then sleeps forever.

2. Then add the label `${Q2_LABEL_KEY}=${Q2_LABEL_VALUE}` to the running Pod `${Q2_NAME}`, without recreating it.
