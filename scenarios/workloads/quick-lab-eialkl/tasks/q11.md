Use context: `kubectl config use-context k8s-south`

A legacy database runs outside the cluster: it listens on port `5432` of host `controlplane` itself (not in a Pod). Apps in namespace `${Q11_NS}` must reach it as `legacy-db:5432`.

Create Service `legacy-db` in `${Q11_NS}` on port `5432` **without a selector**, and the EndpointSlice (or Endpoints) that sends its traffic to that host and port. Test it from Pod `client`: `kubectl -n ${Q11_NS} exec client -- nc legacy-db 5432` must print `legacy-db ok`.
