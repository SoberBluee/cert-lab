Use context: `kubectl config use-context k8s-web`

Create a Pod `${Q15_NAME}` in namespace `${Q15_NS}` with one container `main` running image `${Q15_IMAGE}`. It must keep running.

- Create a Secret `${Q15_ENV_OBJ}` with the key `${Q15_ENV_KEY}` set to `${Q15_ENV_VALUE}`, and give the container `${Q15_ENV_KEY}` as an environment variable taken from it.
- The container requests `${Q15_RES_CPU}` CPU and `64Mi` memory, and is limited to `1` CPU and `${Q15_RES_MEMORY}` memory.
- It must run on `${Q15_PLACE_NODE}`, set directly with `nodeName` (no nodeSelector or affinity).
