Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Deployment `${Q2_APP}` in namespace `${Q2_NS}` runs `2` replicas of `nginx:1.27-alpine`. Practise catching a bad release:

1. Set its progress deadline to `20` seconds and `minReadySeconds` to `3`.
2. Update its image to `nginx:0.0-missing`, and wait until the rollout is reported as failed.
3. On `controlplane`, write the reason of the Deployment's `Progressing` condition to `/opt/course/rollout/reason.txt`.
4. Undo the rollout, so that both replicas run `nginx:1.27-alpine` again.
