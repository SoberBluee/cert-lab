Use context: `kubectl config use-context kubernetes-admin@kubernetes`

1. Create a Pod `${Q2_NAME}` in namespace `${Q2_NS}` with one container `main` running image `${Q2_IMAGE}`. It must keep running.

2. Then add the annotation `${Q2_NOTE_KEY}=${Q2_NOTE_VALUE}` to the running Pod `${Q2_NAME}`, without recreating it.

3. Then add the label `${Q2_LABEL_KEY}=${Q2_LABEL_VALUE}` to the running Pod `${Q2_NAME}`, without recreating it.
