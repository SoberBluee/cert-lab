Container `app` of Deployment `${Q2_APP}` in namespace `${Q2_NS}` needs container `proxy`, which serves on port `9000` but takes a few seconds to start. So `app` crashes and restarts on every rollout.

Change the Deployment so that `app` starts only once `proxy` answers: make `proxy` a native sidecar with a startup probe on port `9000`. The Pod's `app` container must then start without restarting.

Keep the commands of both containers, and do not delete or recreate the Deployment.
