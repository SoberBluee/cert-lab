Use context: `kubectl config use-context kubernetes-admin@kubernetes`

1. Create a StorageClass `${Q5_NAME}` for statically provisioned volumes (provisioner `kubernetes.io/no-provisioner`) with reclaim policy `${Q5_RECLAIM}` and volume binding mode `${Q5_BINDING}`.

   - Claims using it must be allowed to grow (volume expansion).
   - It must be the cluster default StorageClass.

2. Then switch `${Q5_NAME}` from volume binding mode `${Q5_BINDING}` to the other mode. It must keep its name and every other setting.
