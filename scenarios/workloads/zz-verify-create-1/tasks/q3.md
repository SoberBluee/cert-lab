Use context: `kubectl config use-context kubernetes-admin@kubernetes`

1. PersistentVolume `${Q3_NAME}-pv` (StorageClass `manual`, reclaim policy `Retain`) already exists. Create a PersistentVolumeClaim `${Q3_NAME}` in namespace `${Q3_NS}` requesting `${Q3_SIZE}` with access mode `${Q3_ACCESS}` and StorageClass `manual`, bound to `${Q3_NAME}-pv`.

   - Several PVs fit. The claim must pick its volume with a label selector on `tier=${Q3_SELECT_TIER}`.
   - Create a Pod `${Q3_NAME}-app` (image `busybox:1.36`, command `sleep 1d`) that mounts the claim at `${Q3_POD_MOUNT}`.

2. Then delete the claim `${Q3_NAME}` and any Pod using it. `${Q3_NAME}-pv` must not be deleted.

3. Then create a new claim `${Q3_NAME}-v2` (StorageClass `manual`, `${Q3_ACCESS}`, `${Q3_SIZE}`) in the same namespace and bind it to `${Q3_NAME}-pv`, keeping its data.
