1. Create a Pod `${Q1_NAME}` in namespace `${Q1_NS}` with one container `main` running image `${Q1_IMAGE}`. It must keep running.

   - Before `main` starts, an init container `prepare` (image `busybox:1.36`) writes `${Q1_INIT_TEXT}` to `/init/ready` on an `emptyDir` volume that `main` also mounts at `/init`.
   - Create a TLS Secret `${Q1_NAME}-tls` from the certificate and key in `/opt/course/certs/${Q1_NAME}/` on `controlplane`, and mount it read-only at `/etc/tls`.
   - The Pod must be able to pull images from the private registry `${Q1_SECRETS_REGISTRY}` as user `${Q1_SECRETS_USER}` with password `${Q1_SECRETS_PASSWORD}`: keep these credentials in Secret `${Q1_NAME}-pull` and make the Pod use it for its image pulls.
   - The container runs as user `${Q1_SEC_USER}`, with a read-only root filesystem and no privilege escalation.

2. Then change the image of container `main` in the running Pod `${Q1_NAME}` to `${Q1_UPDATE_IMAGE}`, without deleting the Pod.

3. Then add the annotation `${Q1_NOTE_KEY}=${Q1_NOTE_VALUE}` to the running Pod `${Q1_NAME}`, without recreating it.
