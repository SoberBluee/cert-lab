Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Create a Pod `${Q1_NAME}` in namespace `${Q1_NS}` with one container `main` running image `${Q1_IMAGE}`. It must keep running.

- Create a TLS Secret `${Q1_NAME}-tls` from the certificate and key in `/opt/course/certs/${Q1_NAME}/` on `controlplane`, and mount it read-only at `/etc/tls`.
- The Pod must be able to pull images from the private registry `${Q1_SECRETS_REGISTRY}` as user `${Q1_SECRETS_USER}` with password `${Q1_SECRETS_PASSWORD}`: keep these credentials in Secret `${Q1_NAME}-pull` and make the Pod use it for its image pulls.
