Use context: `kubectl config use-context kubernetes-admin@kubernetes`

1. PersistentVolume `${Q1_NAME}-pv` (StorageClass `manual`, reclaim policy `Retain`) already exists. Create a PersistentVolumeClaim `${Q1_NAME}` in namespace `${Q1_NS}` requesting `${Q1_SIZE}` with access mode `${Q1_ACCESS}` and StorageClass `manual`, bound to `${Q1_NAME}-pv`.

   - Several PVs fit. The claim must pick its volume with a label selector on `tier=${Q1_SELECT_TIER}`.

2. Then delete the claim `${Q1_NAME}` and any Pod using it. `${Q1_NAME}-pv` must not be deleted.
