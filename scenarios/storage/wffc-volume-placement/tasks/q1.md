Use context: `kubectl config use-context kubernetes-admin@kubernetes`

The local-path provisioner (`rancher.io/local-path`) runs in this cluster. Volumes it creates live on one node, so the volume must be created where the Pod runs.

1. Create StorageClass `${Q1_SC}` for that provisioner, with volume binding mode `WaitForFirstConsumer` and reclaim policy `Delete`.
2. Create PVC `${Q1_PVC}` in namespace `${Q1_NS}` with that class, `ReadWriteOnce` and `128Mi`. It stays `Pending` for now, which is expected.
3. Create Pod `${Q1_POD}` in `${Q1_NS}` with image `busybox:1.36`, running `sleep 1d`, on node `worker-2`, with the claim mounted at `/data`.
