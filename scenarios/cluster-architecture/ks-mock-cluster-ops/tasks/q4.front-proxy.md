Use context: `kubectl config use-context kubernetes-admin@kubernetes`

The kube-apiserver uses a separate certificate chain when it proxies requests to aggregated APIs such as metrics-server: the front-proxy. Investigate it and write the results on `controlplane`:

1. `/opt/course/q4/front-proxy-issuer`: the issuer of the kube-apiserver's front-proxy **client** certificate, as `openssl` prints it.
2. `/opt/course/q4/front-proxy-flags`: the kube-apiserver flags (with their values) that set the front-proxy CA used to verify that client and the front-proxy client certificate itself, one per line, as they appear in the kube-apiserver manifest.
3. `/opt/course/q4/renew.sh`: the `kubeadm` command that renews **only** the front-proxy client certificate. Do not run it.
