Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Create a ServiceAccount `${Q2_SA}` in namespace `${Q2_NS}` for a batch scheduler. Grant it exactly these permissions:

- In namespace `${Q2_NS}` only: `get`, `list`, `watch`, `create` and `delete` on Jobs; `get`, `list` and `watch` on Pods; and reading Pod logs.
- Cluster-wide: `get` and `list` on Nodes.

It must **not** be able to exec into Pods, create Deployments, or create Jobs in any other namespace. Name the Role `${Q2_SA}-role` and the ClusterRole `${Q2_SA}-nodes`; the binding names are up to you.

Finally, create a Job `${Q2_SA}-probe` in `${Q2_NS}` with image `busybox:1.36` that runs `echo ok` as ServiceAccount `${Q2_SA}`, and let it complete.
