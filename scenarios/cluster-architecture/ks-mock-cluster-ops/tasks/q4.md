Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Investigate the cluster's certificates and write the results on `controlplane`:

1. `/opt/course/q4/apiserver-expiry`: the expiry date of the kube-apiserver serving certificate, as `openssl` prints it.
2. `/opt/course/q4/renew.sh`: the `kubeadm` command that renews **only** that certificate. Do not run it.
3. `/opt/course/q4/kubelet-certs`: for the kubelet on `${Q4_NODE}`, the **Issuer** and the **Extended Key Usage** of both its client certificate (used to talk to the API server) and its serving certificate. Use the format:

```
client issuer: ...
client usage: ...
server issuer: ...
server usage: ...
```
