Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Several contexts were added to the kubeconfig of user `ubuntu` on `controlplane` (`~/.kube/config`). Investigate it and write the results to `/opt/course/q1/` on `controlplane`:

1. `contexts`: the names of all contexts in that kubeconfig, one per line, and nothing else.
2. `current-context.sh`: a shell script that prints the current context of that kubeconfig **without using `kubectl`**. It must stay correct after you switch contexts.
3. `${Q1_USER}.crt`: the client certificate of kubeconfig user `${Q1_USER}`, decoded to PEM.
