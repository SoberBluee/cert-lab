Use context: `kubectl config use-context kubernetes-admin@kubernetes`

The kubeconfig of user `ubuntu` on `controlplane` (`~/.kube/config`) now points at several clusters. Investigate it and write the results to `/opt/course/q1/` on `controlplane`:

1. `servers`: one line per context in that kubeconfig, in the form `<context-name> <api-server-url>`, where the URL is the `server` of the cluster that context uses.
2. `ca.crt`: the CA certificate of cluster `kubernetes` from that kubeconfig, decoded to PEM.
3. `ca-expiry`: the expiry date of that CA certificate, as `openssl` prints it.
