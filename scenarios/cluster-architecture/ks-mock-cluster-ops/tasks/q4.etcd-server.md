Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Investigate the serving certificate of the cluster's etcd (the certificate etcd presents to its clients) and write the results on `controlplane`:

1. `/opt/course/q4/etcd-sans`: all Subject Alternative Names of that certificate (DNS names and IP addresses), as `openssl` prints them.
2. `/opt/course/q4/etcd-expiry`: its expiry date, as `openssl` prints it.
3. `/opt/course/q4/renew.sh`: the `kubeadm` command that renews **only** that certificate. Do not run it.
