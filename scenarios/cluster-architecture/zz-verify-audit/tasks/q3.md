Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Before a release, the on-call engineer wants to know what is broken in namespace `${Q3_NS}-ops`. On `controlplane`:

1. Write the names of the Pods of `${Q3_NS}-ops` that are not ready, one per line, to `/opt/course/audit/unhealthy.txt`. Leave out Pods that ran to completion.
2. Write the name of the Pod that no node will run to `/opt/course/audit/unscheduled.txt`.
3. Write the image that cannot be pulled to `/opt/course/audit/bad-image.txt`.
