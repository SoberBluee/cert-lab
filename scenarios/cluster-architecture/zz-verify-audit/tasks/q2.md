Use context: `kubectl config use-context kubernetes-admin@kubernetes`

A capacity review of namespace `${Q2_NS}-compute` asks two questions. On `controlplane`:

1. Which Pods of `${Q2_NS}-compute` have a container without a memory limit? Write their names, one per line, to `/opt/course/audit/no-memory-limit.txt`.
2. Which 3 Pods of `${Q2_NS}-compute` request the most CPU, adding up all their containers? Write their names to `/opt/course/audit/top-cpu.txt`, one per line, the highest first.
