Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Work on `controlplane` as user `ubuntu`. Add the Helm repository `http://controlplane:8879` under the name `lab`, then install release `${Q3_REL}` from chart `lab/webapp` at version `${Q3_VERSION}` into namespace `${Q3_NS}`.

- Run `${Q3_REPLICAS_COUNT}` replicas, set through a Helm value.
- Expose it through a Service of type `NodePort`, set through a Helm value.
- Keep the release's values in the file `/opt/course/helm/${Q3_REL}-values.yaml` on `controlplane` and install with `-f`. The file sets the Pod annotation `owner: ${Q3_VALUES_OWNER}` (chart value `podAnnotations`).
