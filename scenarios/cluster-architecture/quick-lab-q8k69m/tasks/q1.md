Use context: `kubectl config use-context kubernetes-admin@kubernetes`

The kubeconfig file `/opt/course/kc/can-i/kubeconfig` on `controlplane` has several contexts for namespace `${Q1_NS}`, each with its own user.

1. Write the name of the one context whose user may delete Secrets in namespace `${Q1_NS}` into `/opt/course/kc/can-i/context`.
2. Write the user name the API server knows that context's user by into `/opt/course/kc/can-i/username`.
3. Make that context the current context of `/opt/course/kc/can-i/kubeconfig`. Change nothing else in the file, and do not change any RBAC object.
