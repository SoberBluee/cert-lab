Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Secret `${Q2_SECRET}` in namespace `${Q2_NS}` holds an API key under the key `apikey`. A security review wants to know how it is stored. On `controlplane`, using `etcdctl`:

1. Write the exact etcd key that stores this Secret to `/opt/course/etcd/secret-key.txt`.
2. Read that key from etcd. If you can see the API key in etcd's output as plain text, write `plain` to `/opt/course/etcd/secret-storage.txt`, otherwise write `encrypted`.
