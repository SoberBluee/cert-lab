Use context: `kubectl config use-context kubernetes-admin@kubernetes`

On `controlplane`, connect to etcd with `etcdctl`. Find what it needs in etcd's static Pod manifest. Then write these to files in `/opt/course/etcd/`:

1. `member-id.txt`: the ID of this etcd member, as `etcdctl member list` prints it.
2. `version.txt`: the version the etcd **server** runs, as `etcdctl endpoint status` reports it (for example `3.5.12`).
3. `namespace-keys.txt`: how many keys etcd holds under `/registry/namespaces`.
