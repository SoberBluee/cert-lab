Use context: `kubectl config use-context kubernetes-admin@kubernetes`

1. Work on `controlplane` as user `ubuntu`. Add the Helm repository `http://controlplane:8879` under the name `lab`, then install release `${Q1_REL}` from chart `lab/webapp` at version `${Q1_VERSION}` into namespace `${Q1_NS}`.

   - Expose it through a Service of type `NodePort`, set through a Helm value.
   - Keep the release's values in the file `/opt/course/helm/${Q1_REL}-values.yaml` on `controlplane` and install with `-f`. The file sets the Pod annotation `owner: ${Q1_VALUES_OWNER}` (chart value `podAnnotations`).

2. Then save the manifests that release `${Q1_REL}` installed, as Helm stored them, to `/opt/course/helm/${Q1_REL}-manifest.yaml` on `controlplane`.

3. Then upgrade release `${Q1_REL}` to chart version `2.0.0`, keeping the values you set.
