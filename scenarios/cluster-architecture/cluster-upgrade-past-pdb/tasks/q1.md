The cluster runs Kubernetes 1.36. Upgrade `controlplane` and `${Q1_NODE}` to `1.37.1` with kubeadm, so that:

- the API server, controller manager and scheduler run `v1.37.1`
- on both nodes, `kubeadm`, the kubelet and `kubectl` are `1.37.1`
- the other worker stays on 1.36

Drain `${Q1_NODE}` before you upgrade its kubelet. Deployment `${Q1_APP}` in namespace `${Q1_NS}` runs there, protected by PodDisruptionBudget `${Q1_APP}`: do not change or delete the budget. When you are done, `${Q1_APP}` must run `1` ready replica, as it does now.

Every node must end `Ready` and schedulable. The packages are available through apt on every node.
