Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Ingress `shop` in namespace `${Q1_NS}` serves `shop.${Q1_NS}.lab` over HTTPS with TLS Secret `shop-tls`: `/` goes to Service `web` and `/api` to Service `api`. Migrate it to the Gateway API:

1. Create Gateway `shop-gw` in `${Q1_NS}` (GatewayClass `traefik`) with an HTTPS listener on port `8443` for `shop.${Q1_NS}.lab`, using the same certificate.
2. Create HTTPRoute `shop` with the same paths and backends as the Ingress.
3. Delete Ingress `shop`.

Traefik serves port `8443` listeners on NodePort `30443`. Afterwards both of these must still work:

```bash
curl -k --resolve shop.${Q1_NS}.lab:30443:$(getent hosts controlplane | awk '{print $1}') https://shop.${Q1_NS}.lab:30443/
curl -k --resolve shop.${Q1_NS}.lab:30443:$(getent hosts controlplane | awk '{print $1}') https://shop.${Q1_NS}.lab:30443/api/
```
