Use context: `kubectl config use-context kubernetes-admin@kubernetes`

The apps in namespace `${Q1_NS}` connect to the host name `database`, but there is no such Service here. The database now runs behind Service `${Q1_DB}` in namespace `data-tier`.

Create a Service named `database` in `${Q1_NS}` of type `ExternalName` that points at it. When you are done, this returns the database's page:

```bash
kubectl -n ${Q1_NS} exec client -- wget -qO- http://database/
```
