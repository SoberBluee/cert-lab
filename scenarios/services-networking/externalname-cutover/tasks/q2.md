Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Service `${Q2_SVC}` in namespace `${Q2_NS}` sends traffic to Deployment `${Q2_SVC}`. Its replacement runs behind Service `api-v2` in namespace `platform`.

1. Change Service `${Q2_SVC}` in place, without deleting it, so that it becomes an `ExternalName` Service pointing at `api-v2`. Other tools track this Service, so it must stay the same object.
2. Then delete the old Deployment `${Q2_SVC}`.

When you are done, this returns `api v2`:

```bash
kubectl -n ${Q2_NS} exec client -- wget -qO- http://${Q2_SVC}/
```
