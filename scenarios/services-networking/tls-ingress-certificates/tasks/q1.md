Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Ingress `web` in namespace `${Q1_NS}` serves host `${Q1_SUB}.${Q1_NS}.lab` over plain HTTP. Add HTTPS.

1. On `controlplane`, create a self-signed certificate for `${Q1_SUB}.${Q1_NS}.lab`, valid for `90` days, with that name as a subject alternative name. Write the key to `/opt/course/tls/${Q1_NS}/tls.key` and the certificate to `/opt/course/tls/${Q1_NS}/tls.crt`.
2. Create a TLS Secret `web-tls` in `${Q1_NS}` from those files.
3. Change Ingress `web` so that it terminates TLS for that host with `web-tls`.

Traefik serves HTTPS on NodePort `30443` of every node. When you are done, this returns the nginx welcome page, served with your certificate:

```bash
curl -k --resolve ${Q1_SUB}.${Q1_NS}.lab:30443:$(getent hosts controlplane | awk '{print $1}') https://${Q1_SUB}.${Q1_NS}.lab:30443/
```
