Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Deployment and Service `web` (port `80`) run in namespace `${Q1_NS}`. A certificate and key for `secure.${Q1_NS}.lab` are in `/opt/course/tls/${Q1_NS}/` on `controlplane`.

1. Create TLS Secret `web-tls` in `${Q1_NS}` from those files.
2. Create Gateway `web-gw` in `${Q1_NS}` (GatewayClass `traefik`) with one listener named `https`: protocol `HTTPS`, port `8443`, hostname `secure.${Q1_NS}.lab`, terminating TLS with `web-tls`.
3. Create HTTPRoute `web` in `${Q1_NS}` attached to that listener, sending `/` to Service `web` on port `80`.

Traefik serves port `8443` listeners on NodePort `30443` of every node. When you are done, this returns the nginx welcome page:

```bash
curl -k --resolve secure.${Q1_NS}.lab:30443:$(getent hosts controlplane | awk '{print $1}') https://secure.${Q1_NS}.lab:30443/
```
