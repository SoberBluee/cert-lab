```bash
kubectl -n secure exec client -- wget -qO- -T 3 http://api
```

- Pods in `secure` can resolve names through the cluster DNS
- Pods labelled `role=frontend`, like `client`, can reach `api` on port `80`
- `api` accepts connections only from Pods labelled `role=frontend`; Pod `stranger` stays blocked
- `default-deny` keeps denying everything else
