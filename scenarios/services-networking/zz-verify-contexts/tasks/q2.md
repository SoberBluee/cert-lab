Use context: `kubectl config use-context k8s-alpha`

The cluster's Traefik controller serves Ingress and Gateway API traffic on NodePort `30080` of every node. In namespace `shop`, Deployment `web` is published on two hosts: Ingress `web` serves `www.shop.lab` and HTTPRoute `web` serves `api.shop.lab`. Users report that the app is not reachable on all of them.

Both of these must return the nginx welcome page:

```bash
curl -H 'Host: www.shop.lab' http://controlplane:30080/
curl -H 'Host: api.shop.lab' http://controlplane:30080/
```

Do not change the Deployment or the Service, and do not delete the Ingress or the HTTPRoute.

There may be more than one problem.
