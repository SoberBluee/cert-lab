Use context: `kubectl config use-context kubernetes-admin@kubernetes`

The cluster's Traefik controller serves Ingress and Gateway API traffic on NodePort `30080` of every node. In namespace `${Q5_NS}`, Deployment `${Q5_APP}` is published on two hosts: Ingress `${Q5_APP}` serves `www.${Q5_NS}.lab` and HTTPRoute `${Q5_APP}` serves `api.${Q5_NS}.lab`. Users report that the app is not reachable on all of them.

Both of these must return the nginx welcome page:

```bash
curl -H 'Host: www.${Q5_NS}.lab' http://controlplane:30080/
curl -H 'Host: api.${Q5_NS}.lab' http://controlplane:30080/
```

Do not change the Deployment or the Service, and do not delete the Ingress or the HTTPRoute.
