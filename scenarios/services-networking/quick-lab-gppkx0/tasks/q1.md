Pods in namespace `${Q1_NS}` can no longer reach Service `web` by name. Fix the cluster so that both of these work again:

```bash
kubectl -n ${Q1_NS} exec ${Q1_CLIENT} -- wget -qO- -T 3 http://web
kubectl -n ${Q1_NS} exec ${Q1_CLIENT} -- nslookup web.${Q1_NS}.svc.cluster.local
```

Keep CoreDNS as the cluster DNS with `2` replicas, and keep forwarding other names to the node's resolver. Do not delete or recreate Deployment `web` or Service `web`. You may recreate Pod `${Q1_CLIENT}` with the same name, image and command.
