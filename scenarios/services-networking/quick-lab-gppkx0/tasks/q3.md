Use context: `kubectl config use-context k8s-gamma`

1. Create a StorageClass `${Q3_NAME}` for statically provisioned volumes (provisioner `kubernetes.io/no-provisioner`) with reclaim policy `${Q3_RECLAIM}` and volume binding mode `${Q3_BINDING}`.

   - Claims using it must be allowed to grow (volume expansion).
   - It must be the cluster default StorageClass.

2. Then switch `${Q3_NAME}` from volume binding mode `${Q3_BINDING}` to the other mode. It must keep its name and every other setting.
