Use context: `kubectl config use-context k8s-south`

1. Work on `controlplane` as user `ubuntu`. Add the Helm repository `http://controlplane:8879` under the name `lab`, then install release `${Q2_REL}` from chart `lab/webapp` at version `${Q2_VERSION}` into namespace `${Q2_NS}`.

   - Expose it through a Service of type `NodePort`, set through a Helm value.

2. Then upgrade release `${Q2_REL}` to chart version `2.0.0`, keeping the values you set.

3. Then save the manifests that release `${Q2_REL}` installed, as Helm stored them, to `/opt/course/helm/${Q2_REL}-manifest.yaml` on `controlplane`.
