Use context: `kubectl config use-context k8s-blue`

The kubeconfig file `/opt/course/kc/identity/kubeconfig` on `controlplane` holds several users. Do not change it. For its user `${Q12_USER}`:

1. Write the user name the API server knows it by, the Common Name of its client certificate, into `/opt/course/kc/identity/username`.
2. Write the groups its client certificate puts it in, one per line, into `/opt/course/kc/identity/groups`.
3. Write the date and time its client certificate expires, as `openssl` prints it, into `/opt/course/kc/identity/expiry`.
4. Write its client key, decoded to PEM, into `/opt/course/kc/identity/${Q12_USER}.key`.
