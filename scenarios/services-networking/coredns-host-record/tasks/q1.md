An old server outside the cluster has no DNS record. Make every Pod resolve `${Q1_HOST}` to `${Q1_IP}` through the cluster DNS, without changing any Pod or Deployment. Every other name must keep resolving as before:

```bash
kubectl -n ${Q1_NS} exec dns-test -- nslookup ${Q1_HOST}
kubectl -n ${Q1_NS} exec dns-test -- nslookup web.${Q1_NS}.svc.cluster.local
```

Keep CoreDNS running with `2` replicas.
