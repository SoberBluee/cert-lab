Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Services must also resolve under the DNS domain `${Q1_DOMAIN}`, the same way they do under `cluster.local`: `web.${Q1_NS}.svc.${Q1_DOMAIN}` must return the ClusterIP of Service `web` in namespace `${Q1_NS}`, and `cluster.local` names must keep working.

1. First save the current CoreDNS ConfigMap as YAML to `/opt/course/coredns/coredns-backup.yaml` on `controlplane`.
2. Then change the CoreDNS configuration so that both of these resolve:

```bash
kubectl -n ${Q1_NS} exec dns-test -- nslookup web.${Q1_NS}.svc.cluster.local
kubectl -n ${Q1_NS} exec dns-test -- nslookup web.${Q1_NS}.svc.${Q1_DOMAIN}
```

Keep CoreDNS running with `2` replicas.
