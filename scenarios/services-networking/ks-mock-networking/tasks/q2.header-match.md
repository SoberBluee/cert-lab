Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Namespace `${Q2_NS}` contains two Deployments with Services: `frontend` (Service port `80`) and `api` (Service port `8080`).

Create an HTTPRoute `app` in namespace `${Q2_NS}` that attaches to listener `web` of the existing Gateway `traefik-gateway` in namespace `traefik`, for hostname `app.${Q2_NS}.lab`:

- requests carrying the header `X-Backend: api` go to Service `api` on port `8080`, whatever their path
- all other requests go to Service `frontend` on port `80`

The Gateway is exposed on NodePort `30080` of every node. When you are done, these must work:

```
curl -H "Host: app.${Q2_NS}.lab" http://controlplane:30080/                       # frontend
curl -H "Host: app.${Q2_NS}.lab" -H "X-Backend: api" http://controlplane:30080/api/   # api
```

If something in the namespace prevents that, fix it without changing either Deployment.
