Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Find out how Pod networking is set up and write each answer to a file on `controlplane`:

1. `/opt/course/q4/node-cidrs`: one line per node in the form `<node-name> <pod-cidr>`, with the Pod CIDR the controller manager assigned to that node
2. `/opt/course/q4/cni`: the name of the CNI plugin the cluster uses
3. `/opt/course/q4/cni-config`: the full path of the CNI configuration file the container runtime loads on the nodes
