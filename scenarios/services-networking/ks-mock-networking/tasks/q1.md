Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Namespace `${Q1_NS}` runs the Pods `client` (label `role=client`), `db` (`role=db`, listening on TCP `5432`) and `cache` (`role=cache`), each behind a Service of the same name.

Create a NetworkPolicy `client-egress` so that Pod `client` may only open outgoing connections to:

- Pods with label `role=db` on TCP port `5432`
- cluster DNS on port `53` (UDP and TCP), so that `client` can still use the Service name `db`

Everything else from `client` must be blocked, including `cache` and the Kubernetes API server. The egress of every other Pod in `${Q1_NS}` must stay exactly as open as it is now. Do not delete any existing NetworkPolicy.
