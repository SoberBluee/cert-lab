Namespace `${Q1_NS}` runs the Pods `client` (label `role=client`), `db` (`role=db`, listening on TCP `5432`) and `cache` (`role=cache`), each behind a Service of the same name. Two more namespaces exist: `${Q1_NS}-mon` and `${Q1_NS}-dev`.

Create a NetworkPolicy `db-ingress` in `${Q1_NS}` so that Pod `db` only accepts incoming connections on TCP port `5432` from:

- Pods with label `role=client` in `${Q1_NS}`
- Pods with label `role=probe`, but only if they run in a namespace labelled `team=monitoring`

Every other source must be blocked, including `cache`, every Pod in `${Q1_NS}-dev`, and Pods in `${Q1_NS}-mon` without the label `role=probe`. Do not change or delete any existing NetworkPolicy, Pod or namespace label.
