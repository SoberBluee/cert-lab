Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Find out how Services and DNS are configured and write each answer, and nothing else, to a file on `controlplane`:

1. `/opt/course/q4/nodeport-range`: the port range NodePorts are allocated from, in the form `<first>-<last>`
2. `/opt/course/q4/dns-upstream`: where CoreDNS forwards queries for names outside the cluster, exactly as configured
3. `/opt/course/q4/cluster-domain`: the cluster's DNS domain
