Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Namespace `${Q2_NS}` contains two Deployments with Services: `frontend` (Service port `80`) and `api` (Service port `8080`).

Expose them on two hostnames through listener `web` of the existing Gateway `traefik-gateway` in namespace `traefik`, with one HTTPRoute each in `${Q2_NS}`:

- HTTPRoute `web`: hostname `www.${Q2_NS}.lab`, all requests to Service `frontend` on port `80`
- HTTPRoute `api`: hostname `api.${Q2_NS}.lab`, all requests to Service `api` on port `8080`

The Gateway is exposed on NodePort `30080` of every node. When you are done, both of these must work:

```
curl -H "Host: www.${Q2_NS}.lab" http://controlplane:30080/
curl -H "Host: api.${Q2_NS}.lab" http://controlplane:30080/api/
```

If something in the namespace prevents that, fix it without changing either Deployment.
