Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Find out how the cluster network is configured and write each answer, and nothing else, to a file on `controlplane`:

1. `/opt/course/q4/pod-cidr`: the IP range Pods get their addresses from, as configured for the controller manager
2. `/opt/course/q4/service-cidr`: the IP range Services get their ClusterIPs from
3. `/opt/course/q4/proxy-mode`: the mode kube-proxy is running in (for example `ipvs`)
4. `/opt/course/q4/dns-ip`: the ClusterIP of the cluster DNS Service
