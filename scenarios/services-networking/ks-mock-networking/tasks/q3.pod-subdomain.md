Use context: `kubectl config use-context kubernetes-admin@kubernetes`

In namespace `${Q3_NS}`, a single Pod needs a stable DNS name without using a StatefulSet:

1. Create a headless Service `${Q3_STS}-hl` for port `80` that selects Pods with label `app=${Q3_STS}`.
2. Create a Pod `${Q3_STS}-primary` with image `nginx:1.27-alpine` and label `app=${Q3_STS}`, so that it is reachable inside the cluster as `primary.${Q3_STS}-hl.${Q3_NS}.svc.cluster.local`.
3. Write that fully qualified DNS name to `/opt/course/q3/fqdn` on `controlplane`.
