Pods in namespace `${Q15_NS}` can no longer reach Service `web` by name. Fix the cluster so that both of these work again:

```bash
kubectl -n ${Q15_NS} exec ${Q15_CLIENT} -- wget -qO- -T 3 http://web
kubectl -n ${Q15_NS} exec ${Q15_CLIENT} -- nslookup web.${Q15_NS}.svc.cluster.local
```

Keep CoreDNS as the cluster DNS with `2` replicas, and keep forwarding other names to the node's resolver. Do not delete or recreate Deployment `web` or Service `web`. You may recreate Pod `${Q15_CLIENT}` with the same name, image and command.
