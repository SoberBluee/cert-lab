Use context: `kubectl config use-context k8s-blue`

1. On `controlplane`, find when the API server's serving certificate expires. Write its expiry date to `${Q14_EXPIRY}`, exactly as `openssl x509 -enddate` prints it after `notAfter=` (for example `Jan  1 00:00:00 2027 GMT`).

2. Then renew the API server's serving certificate with `kubeadm`, and make the running API server serve the renewed certificate.
