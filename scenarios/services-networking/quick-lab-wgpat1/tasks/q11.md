Use context: `kubectl config use-context k8s-web`

Deployment `web` runs in namespace `${Q11_NS}`. Create Service `web-lb` of type `LoadBalancer` for it, on port `80` with node port `${Q11_NODEPORT}`, that keeps the client source IP (`externalTrafficPolicy: Local`).

This cluster has no load balancer controller, so the external IP stays pending. The app must still answer on node port `${Q11_NODEPORT}` of a node that runs one of its Pods.
