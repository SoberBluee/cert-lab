Use context: `kubectl config use-context k8s-core`

The CI system authenticates as ServiceAccount `ci` in namespace `${Q8_NS}`. On `controlplane`, create a token for that ServiceAccount that is valid for exactly `1` hour, and write the token, and nothing else, to `/opt/course/token/ci.token`.

Do not create a Secret for it: the token must not be long-lived.
