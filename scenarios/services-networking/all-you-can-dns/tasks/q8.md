Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Pods in namespace `${Q8_NS}` can no longer reach Service `web` by name. Fix the cluster so that both of these work again:

```bash
kubectl -n ${Q8_NS} exec client -- wget -qO- -T 3 http://web
kubectl -n ${Q8_NS} exec client -- nslookup web.${Q8_NS}.svc.cluster.local
```

Keep CoreDNS as the cluster DNS with `2` replicas, and keep forwarding other names to the node's resolver. Do not delete or recreate Deployment `web` or Service `web`. You may recreate Pod `client` with the same name, image and command.
