Use context: `kubectl config use-context kubernetes-admin@kubernetes`

Deployment `${Q2_APP}` in namespace `${Q2_NS}` serves its app on a container port named `http`, and its metrics on one named `metrics`.

Create a `NodePort` Service `${Q2_APP}` with two ports:

- `web`: port `80`, forwarding to the container port named `http`, on nodePort `${Q2_NODEPORT}`
- `metrics`: port `9100`, forwarding to the container port named `metrics`

Refer to the container ports by name, so that their numbers can change later without touching the Service. When you are done, this returns `app ok`:

```bash
curl http://controlplane:${Q2_NODEPORT}/
```
