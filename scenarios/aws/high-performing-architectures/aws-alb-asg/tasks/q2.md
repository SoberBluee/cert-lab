Traffic varies through the day. Run the application in an Auto Scaling group that grows with load and replaces instances the load balancer considers unhealthy.

- Create a launch template `app-lt`: AMI `ami-0abcdef1234567891` (Amazon Linux 2023), instance type `t3.micro`, security group `app-sg`.
- Create an Auto Scaling group `app-asg` from `app-lt` with a minimum of **2**, a maximum of **6** and a desired capacity of **2** instances, in `app-a` and `app-b`, registered with `app-tg`.
- Use the **load balancer health check** (not only EC2 status checks), with a **120 second** grace period.
- Add a target tracking scaling policy named `cpu-50` that keeps the group's average CPU utilization at **50%**.

Floci records the group's configuration but does not start its instances, so check your work with `describe` commands.
