The VPC `web-vpc` has public subnets `public-a` and `public-b`, application subnets `app-a` and `app-b` (one of each per Availability Zone), and the security groups `alb-sg` and `app-sg`. The application listens on port `${APP_PORT}` and answers health checks on `${HEALTH_PATH}`.

- Create a target group `app-tg`: protocol HTTP, port `${APP_PORT}`, target type `instance`, in `web-vpc`. Health checks go to `${HEALTH_PATH}` every **15 seconds**, and a target is healthy after **2** consecutive successes.
- Create an internet-facing Application Load Balancer `web-alb` in `public-a` and `public-b`, with the security group `alb-sg`.
- Add a listener on HTTP port 80 that forwards to `app-tg`.
