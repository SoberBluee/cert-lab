The bucket is versioned, so every overwrite and delete keeps the old version, and failed uploads leave invisible parts behind. You pay for both.

Add a second lifecycle rule with the ID `cleanup`, enabled, that applies to the **whole bucket**:

- permanently delete noncurrent object versions **30 days** after they become noncurrent
- abort multipart uploads that are still incomplete **7 days** after they started

Keep the `logs-tiering` rule in place.
