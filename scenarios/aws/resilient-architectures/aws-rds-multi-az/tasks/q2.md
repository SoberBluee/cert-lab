The orders service needs a MySQL database that survives the loss of an Availability Zone without manual intervention.

Create an RDS DB instance `${DB_ID}`:

- engine `mysql`, instance class `db.t3.micro`, 20 GiB of storage
- master username `admin`, with a password of your choice
- a **Multi-AZ** deployment
- in the DB subnet group `db-subnets`, with `db-sg` as its only security group
- not publicly accessible

Floci runs the database as a real MySQL container, so the first start can take a minute while Docker pulls the image.
