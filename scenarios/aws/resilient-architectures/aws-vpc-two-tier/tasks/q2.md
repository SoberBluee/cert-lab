The load balancers will live in the public subnets, so those need a route to the internet.

- Create an internet gateway named `${VPC_NAME}-igw` and attach it to `${VPC_NAME}`.
- Create a route table named `public-rt` whose default route (`0.0.0.0/0`) goes to that internet gateway, and associate it with `public-a` and `public-b`.
- Make instances launched in `public-a` and `public-b` receive a public IPv4 address automatically.
