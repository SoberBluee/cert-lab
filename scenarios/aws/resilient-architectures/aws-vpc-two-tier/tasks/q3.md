The application servers in the private subnets must download updates from the internet, but nothing on the internet may open a connection to them.

- Allocate an Elastic IP and create a NAT gateway named `${VPC_NAME}-nat` in `public-a`.
- Create a route table named `private-rt` whose default route goes to the NAT gateway, and associate it with `private-a` and `private-b`.

The private subnets must not route to the internet gateway.
