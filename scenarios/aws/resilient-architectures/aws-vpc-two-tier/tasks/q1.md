A new application needs its own network in `us-east-1`, spread over two Availability Zones so that losing one zone does not take it down.

- Create a VPC named `${VPC_NAME}` with the CIDR block `${NET}.0.0/16`, and enable DNS hostnames in it.
- Create four subnets in `${VPC_NAME}`, each with a `Name` tag:

| Name | CIDR | Availability Zone |
|---|---|---|
| `public-a` | `${NET}.1.0/24` | `us-east-1a` |
| `public-b` | `${NET}.2.0/24` | `us-east-1b` |
| `private-a` | `${NET}.11.0/24` | `us-east-1a` |
| `private-b` | `${NET}.12.0/24` | `us-east-1b` |
