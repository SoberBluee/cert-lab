- Create an SNS standard topic named `${TOPIC}`.
- Subscribe `billing` and `shipping` to it, both with **raw message delivery**, so the consumers get the event body without the SNS envelope.
- Give each queue an access policy that lets `sns.amazonaws.com` send messages to it only when the source is `${TOPIC}`.

Try it: `aws sns publish --topic-arn <topic ARN> --message '{"orderId": 42}'`, then receive from both queues.
