Give `${ROLE}` an inline policy named `read-${PREFIX}` that follows least privilege. The role must be able to:

- read (`s3:GetObject`) any object under `${PREFIX}/` in `app-${SUFFIX}`
- list (`s3:ListBucket`) the bucket `app-${SUFFIX}`

It must not be able to write or delete objects, read anything outside `${PREFIX}/`, or touch the bucket `audit-${SUFFIX}`. The checks use `aws iam simulate-principal-policy`, which you can run yourself.
